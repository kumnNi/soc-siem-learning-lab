# AAA Security Model
## 1. Why is the AAA Security Model relevant to my SOC project
The AAA Security Model is relevant to my SOC project because it helps me understand and analyze user authentication, access permissions and user activities.



Other important security models and concepts include:
- Zero Trust
- Defense in Depth
- Risk Management

These concepts are also relevant to information security and SOC operations.

## 2. Definition of AAA 
AAA stands for :
-  Authentication
-  Authorization 
-  Accounting. 

It is a security model that describes :
- who are you ? (Authentication)
- what are you allowed to do ? (Authorization)
- what did you do ? (Accounting)
